# 时尚趣味拼贴效果库

用户对初版的修正优先于旧模板：减少规整牛仔大底、等大矩形相框、粉紫卡通布贴和无层级的大字文案；增加异形剪贴、真实小物材质、年轻的色彩冲突与非对称层次。下列参考只供审美提炼，不是可直接贴进用户成片的素材。

当前布局优先遵循 [六项规则与新参考](irregular-axis.md)。3–4 页逐页都有小元素与荧光点缀；图13格布重新启用、牛仔底继续停用。

## 配色组：一轮选一组，不全混用

- **Cherry / cream / acid**：奶油纸 `#F0E9D9`，樱桃红 `#BB1635`，荧光柠檬黄 `#E9FA32`，少量银色和黑色笔迹。适合当前花墙照片及玩趣人像。
- **Kraft / tomato / sky**：牛皮纸、番茄红、浅天蓝，局部亮黄。适合生活记录、食物、旅行；参考 04、05。
- **Silver / pink / ink**：银色首饰、淡泡泡粉、黑色、极少荧光绿；不做大片粉紫扁平卡通。适合 Y2K 趣味人像。

以照片原色为最大色块。高饱和点缀成组出现即可，避免每张纸和每个字都争抢焦点。金属亮点贵在少而真实，不把银色渐变圆点冒充水钻。

## 轮廓和排版

至少让几个主要图层拥有不同外轮廓：主体剪影、心形照片、撕纸照片、票据、星芒、窄布条或透明包装。控制视觉主次，一个主主体搭配环境细节；一张来源照片不通过重复同一张脸来填满多个页面。

主体可越过底片边缘；装饰可越过照片轮廓；相邻图层错开角度和高度。接近参考的是围绕中轴聚合的异形剪贴体，而不是三块一样大的看板。保持白色背景和空间环绕，不因参考是盒子或实体本子就改成纯平铺拍照。

## 点缀类别

- **主体抠图描边**：优先保留原图像素，沿头发／身体真实轮廓提取；添加细至中等宽度的白色纸边，必要时加一圈极细对比色。原图被挡住的手或身体不要补画，可改成合理的半身剪贴。
- **水钻／珠宝**：使用独立透明 PNG，检查内部开口也透明。适合小心框、短链、耳饰形挂坠、星形胸针；少量，不要复制参考品牌。
- **荧光标签**：窄矩形、贴纸圆点、一个局部爆炸形，搭配一两个小单词；底色高亮但面积克制。
- **手绘涂鸦**：细线爱心、星芒、箭头、圈注、随手下划线。要像笔画，避免粗描边幼儿卡通。
- **真实小物**：回形针、透明包装、邮票、票据和来自原图的花、食物等。没有来源时可以生成通用装饰，但不能冒充用户真实经历。

本库附有模型生成的 [银色水钻心形框](../assets/silver-heart.png)，只作为原创通用装饰。照片与人物不进入通用素材库。

## 文字层级

文字层级以用户要求为准。当前风格采用轴心上方的轻量手写字，文字组宽度约为拼贴主体的 1/3，详见 [异形轴心规则](irregular-axis.md)。其他主题可用英文单词、小号手写体、低密度排布，通常一面一两处即可。推荐词：bloom、play、sweet、xo、little joy、keep it。没有明确要求时，不默认使用大写宣传标语、中文大标题、长段文字。文字必须服从照片；用户说小字号，就不要为了让分镜缩略图能读清而放大。

## 可复用制作工具

`scripts/collage_assets.py` 提供纸边、轮廓遮罩、描边、手写字、格纹与线描函数。先给 `crop` / `cutphoto` 传原照片和归一化裁切框；不要复用上一位用户的人脸位置。人体抠图需要独立语义检查，不能用通用裁框冒充自动抠图。

`scripts/diary.py --photos ...` 的 birthday/denim 预设仍是技术初稿。按此库修改 scene.json 与纹理后再交付；不要把成功编码当成风格合格。
